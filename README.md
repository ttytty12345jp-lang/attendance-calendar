# 出欠カレンダー

A児・B児（名前は変更可）の毎日の遅刻・欠席を記録し、**入力日までの稼働日を母数にした割合**を日々自動算出するツール。

利用者ごとに独立した記録を持ち、PC・スマホなど複数の端末から同じ記録を使えます。
（QさんはA児・B児、WさんはC児・D児、というように互いの記録は見えません）

- **公開して使う**（推奨）… メールアドレスでログインし、記録はクラウド保存。端末をまたいで同期されます。
  セットアップは [SETUP.md](SETUP.md) を参照
- **1台だけで使う** … `index.html` をブラウザで開き「ログインせず、この端末だけで使う」を選択。
  記録はその端末のブラウザ内だけに保存されます

## 使い方

1. **集計開始日**（既定：年度開始の 4/1）と**基準日**（既定：今日。「今日にする」ボタンで更新）を設定
2. カレンダーの各日のセルで、児童名のボタンをクリックして状態を切替
   `出席 ○ → 遅刻 → 欠席 → 出席`
3. 上部の集計パネルが即座に再計算される

## 割合の定義

```
遅刻率 = 遅刻日数 ÷ 登校日数
欠席率 = 欠席日数 ÷ 登校日数
出席率 = (登校日数 − 欠席日数) ÷ 登校日数
```

**登校日** ＝ 集計開始日〜基準日 のうち登校日として数える日。既定は次のとおりで、
そこから **日付ごとに自由に切り替えられます**。

- 平日 → 登校日
- 土曜・日曜 → 休業日
- 祝日 → 休業日（「国民の祝日に関する法律」に基づき自動計算。振替休日・国民の休日を含む）

### 登校日⇔休業日の切り替え

土日・祝日かどうかにかかわらず、どの日でも反転できます（土曜授業、夏休み、臨時休校、祝日の登校日など）。

- 日付セルにカーソルを合わせると右上に現れる **「休」/「登」** ボタン
- または **セルを右クリック**
- 期間指定なら **「期間をまとめて設定」**（休業日にする／登校日にする／既定に戻す）

既定と違う設定にした日は「登校日」「休業日」と青字で表示されます。既定と同じ状態に戻すと、
その印は自動的に消えます。休業日はグレー表示になり、母数にも遅刻・欠席にも数えません。

## データの保存

**ログインして使う場合**、記録はSupabase上に保存され、同じメールアドレスでログインした
すべての端末で同期されます。他人からは読めません（Row Level Securityで本人の行に限定）。
電波が無いときの入力は端末内にため込み、つながったときに自動送信されます
（画面上部に「未送信 n件」と表示）。

**ログインせずに使う場合**、記録はそのブラウザ内（localStorage）だけに保存されます。
ブラウザのデータを消すと記録も消えるため、定期的に **CSVで書き出し** てバックアップしてください。
書き出したCSVは「CSVを読み込み」で復元できます。

CSVの形式（末尾に `#` で始まる集計サマリ行が付きます）:

```
日付,区分,A児,B児
2026-05-11,,遅刻,
2026-07-21,休業日,,
2026-09-05,登校日,,欠席
```

「区分」列は既定と異なる日だけ `休業日` / `登校日` が入ります。
